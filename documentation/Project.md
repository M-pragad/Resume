# Project

- Phishing URL Detection Website: Developed a phishing detection system using ensemble ML models (XGBoost, Random
Forest), achieving 97.35% accuracy with optimized processing performance.

- Ticket-Raising System: Built RESTful APIs using Express and MongoDB for efficient handling for ticket creation, retrieval,
and status updates

- Real-Time Auction Platform: Designed and built a full-stack real-time auction application with dynamic UI updates,
WebSocket-driven bid streaming, and MongoDB persistence. Integrated responsive frontend (HTML/CSS/JS) with
event-based backend, enabling seamless user interaction without polling.
